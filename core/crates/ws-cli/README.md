# ws-cli

Responsibility: a headless host for command submission, logical scheduling, recording and independent replay. Workspace layer 5, alongside other adapters; it depends on `ws-sim` and earlier layers, and nothing depends on it. It uses only the standard library plus internal crates at runtime. Domain crates retain their no-filesystem/environment/clock rule.

Owned state: CLI arguments, the world, file handles and tape frame/operation/observation counters. It owns no separate simulation state and emits no domain events itself. Every command/event observation is generated by the same core handlers used in normal operation. Replay never applies a recorded outcome or event as a mutation.

From `core/`:

```sh
cargo run --locked -p ws-cli -- run --seed 42 --ticks 10000 --journal /tmp/world.wsjr --hash-every 100
cargo run --locked -p ws-cli -- replay --journal /tmp/world.wsjr
```

The destination must not exist: a recording never silently overwrites a previous artifact. A recording includes configuration, source/compiler/target/profile build identity, platform and a completion footer. Use the same compiled binary for record and replay; changed code/build/platform fails compatibility. A file without a valid footer is incomplete and cannot verify. These are reproducibility/debug artifacts, **not saves**; do not put credentials, sensitive data or machine authorization URLs in scripts/artifacts.

`--script FILE` accepts comments beginning with `#`, and these operations, one per line:

```text
noop
scale paused
flush
noop
flush
scale 10
flush
lod all 2
step 7000
lod all 1
flush
scale 1
```

`noop`, `scale paused|1|10|100`, `lod all 1|2` and `lod DECIMAL_RAW_ENTITY_ID 1|2` submit without applying. `flush` applies at the current boundary; `step N` flushes before each physical tick. Repeated flushes can occur at the same paused tick. Unknown valid entity IDs receive journaled semantic rejection. `--ticks N` is the **total physical tick budget**, including script steps; script steps exceeding it fail. After the script, the runner finishes the remaining ticks regardless of pacing scale. The default hash interval is one; all physical steps have tape checkpoints even with less frequent printed hashes. `--batch FILE` submits one exact canonical wire batch before the script, useful for capacity/rejection reproduction; max 65,536 bytes.

Invariants: all framed lengths are bounded and checked before body allocation/read; kind-specific schemas reject trailing bytes/unknown versions. Replay compares full journal/event observations, operation checkpoints and completion counts, including pending input. Environmental stop fences are distinguished from independently reproduced deterministic failures. See [codec and fixtures](../../../docs/technical-prototype/command-event-tape.md). Unit tests exercise maximum-size batches, malformed frames and environmental stops; the integration test invokes the actual CLI in separate processes with mixed commands, L1/L2 arrivals, and corrupt/incomplete artifacts.
